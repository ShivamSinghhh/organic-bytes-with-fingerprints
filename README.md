# organic-bytes-with-fingerprints

100% hand-written code in 2026. No AI additives, just my fingerprints on every byte.

## Why this repo exists

For the past two years most of my work has been AI-assisted development: building agentic systems, full-stack features and backend services alongside AI coding tools. That speeds up delivery, but it also means less time spent writing logic line by line.

This repo is a deliberate counterbalance. Every project here is planned, written, debugged and refactored by me, to keep my fundamentals sharp: problem decomposition, clean Python, and debugging without a safety net.

## Ground rules

- No AI-generated code. I use docs, the debugger, and my own reasoning.
- Each project is complete and playable or usable, not just a snippet.
- Code follows PEP 8, uses modern type hints, and passes Ruff linting.
- After it works, I refactor it: clear names, small functions, no dead code.


More Games/projects will be added over time.

## Tech and tooling

- Python 3.12
- Standard library only, unless a project needs more
